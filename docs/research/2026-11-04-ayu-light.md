# Ayu Light (Bordered): адаптация 17 ролей

Дата: **04.11.2026**. Добавляется только одна палитра, `ayu-light`, группа LIGHT.
Отображаемое имя **Ayu Light (Bordered)** уточняет вариант, как у прежней Ayu Dark.
В исходном manifest это label «Ayu Light», ID «Ayu Light Bordered», файл `ayu-light.json`.
Unbordered и светлая Dracula не добавляются.

Источник — Ayu **1.5.0**, commit `7f438df22446f02e79cdfc2f3771b0b273f34654`.
Прочитаны официальные [manifest](https://github.com/ayu-theme/vscode-ayu/blob/7f438df22446f02e79cdfc2f3771b0b273f34654/package.json),
[Light JSON](https://github.com/ayu-theme/vscode-ayu/blob/7f438df22446f02e79cdfc2f3771b0b273f34654/ayu-light.json)
и [MIT](https://github.com/ayu-theme/vscode-ayu/blob/7f438df22446f02e79cdfc2f3771b0b273f34654/LICENSE), Ike Kurghinyan, 2016.
Текст MIT побайтово совпадает с уже включённым `ayu-LICENSE.txt`.
SHA-256 JSON: `3d748e7a3666978e34fbab2830ce3c311da24a8b38d7a955fe833ca1d536f646`.
Прежняя Ayu Dark использует закреплённую 1.4.1 и сохраняется побайтово;
новая Light не обновляет остальные схемы. Общий механизм 0.1.19 не меняется.

Alpha-композиция выполняется в sRGB-каналах с 8-bit alpha и округлением
до ближайшего целого; прозрачности не отсекаются. Для border подложка — panel,
для выделения и строки — editor.background. Hover — исходный непрозрачный фон
виджета, а не прозрачное подсвечивание редактора.

Текстовые цвета затемнены умножением всех трёх исходных sRGB-каналов на общий
коэффициент до контраста не ниже 4.6:1 на editor/line/hover. Такой способ сохраняет
соотношение каналов, но не заявляет точное сохранение perceptual hue.
Error рассчитан для panel; warning использует тот же RGB, что accent, поскольку
в источнике оба имеют #F29718. Disabled использует читаемый comment.
Native BSL font styles сохраняются; исходный italic comment не переносится.
