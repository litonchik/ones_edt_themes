# Установка и использование тем EDT

Плагин 0.1.16 рассчитан на **1С:EDT 2026.1.2+2 и 2026.1.3+25 с Java 17**, а также **2026.2.2+21 с Java 25**.
Windows x64 проверена. Запуск на macOS x64 разрешён; пользователь подтвердил работу
версии 0.1.5 на Mac. Подробные сценарии и конфигурация Mac отдельно не сообщены.
Новые палитры One Dark Pro, Dracula, GitHub Dark Default, Winter is Coming (Dark Blue), Night Owl, Ayu Dark (Bordered), Shades of Purple, Noctis Minimus и Visual Studio Dark (C/C++) отдельно на Mac не проверены; последующие подтверждения работы не содержат сведений об ОС.
Darcula, Monokai, One Dark Pro, Dracula, GitHub Dark Default, Winter is Coming (Dark Blue), Night Owl, Ayu Dark (Bordered), Shades of Purple, Noctis Minimus и Visual Studio Dark (C/C++) — профили цветов поверх штатной Dark.
В стандартном селекторе Eclipse тема называется Dark; палитры доступны на странице плагина.

Основной способ установки — сайт обновлений:
`https://litonchik.github.io/ones_edt_themes/repository/`.
ZIP для офлайн-установки доступен в
[Releases](https://github.com/litonchik/ones_edt_themes/releases/latest).
[Выполненные проверки и ручная матрица](testing/mvp-validation.md) описывают границы проверки.
[Проверки редактора палитры 0.1.4](testing/palette-validation.md) приведены отдельно.

## Установка

1. Откройте **Справка → Установить новое ПО…** (Help → Install New Software).
2. Нажмите **Добавить…**, задайте имя **Темы EDT** и адрес
   `https://litonchik.github.io/ones_edt_themes/repository/`.
3. Выберите компонент **Темы EDT — цветовые палитры**, продолжите установку.
4. В плане установки должны быть только `ru.litonchik.edt.themes` и его feature.
   Плагин не поставляет Eclipse/EDT bundles. Если мастер предлагает обновлять базовую платформу,
   прекратите установку: этот план не соответствует проверенной поставке.
5. Собственный bundle не подписан сертификатом; стандартный мастер Eclipse может запросить
   доверие к неподписанному компоненту. Подтвердите, если используете указанный сайт или проверенный архив.
6. Перезапустите EDT.

После добавления сайта новые версии доступны через **Справка → Проверить обновления**.
Если ранее устанавливали плагин из ZIP, сначала добавьте сайт обновлений.
Сайт содержит последний стабильный релиз; тестовые prerelease-сборки в него не входят.

Для офлайн-установки скачайте `edt-themes-0.1.16.zip` и `edt-themes-0.1.16.zip.sha256`
из Releases, сравните `Get-FileHash ./edt-themes-0.1.16.zip -Algorithm SHA256`
с контрольной суммой и используйте **Добавить… → Архив…**.
GitHub Source code ZIP содержит исходники и для установки не подходит.
При локальной сборке оба установочных файла появляются в игнорируемом `dist/`.
Для обновления с 0.1.0–0.1.15 можно также добавить новый архив и выбрать версию 0.1.16.
Исходный снимок цветов остаётся совместимым; предварительно сбрасывать рабочую палитру не требуется.
Локальные ZIP прежних версий могут сохраняться в `dist`, но не входят в текущее
дерево исходников Git. Для опубликованных версий используйте вложения Releases.
В 0.1.10 исправлены разделители Winter: после обновления откройте страницу тем
и нажмите **Применить**. Если роль **Фон панелей** менялась лично, выберите её
и нажмите **Вернуть цвет стиля → Применить**; остальные личные цвета сохранятся.

На Mac устанавливается тот же p2 ZIP через Help → Install New Software.
Открывайте настройки через меню приложения EDT (Preferences/Settings), затем найдите
«Темы EDT». Нужен x86_64 runtime EDT: Intel Mac либо x86 EDT/JVM через Rosetta
на Apple Silicon. Native aarch64 runtime пока не разрешён. Проверки версий
Eclipse/Xtext/BSL UI/theming UI остаются прежними. Для первого запуска используйте
отдельную тестовую установку и чистую Mac workspace; Windows workspace с журналом
исходных цветов/шрифта не переносите. [Матрица проверки Mac](testing/macos-validation.md).

Если появляется сообщение о другой Java, выберите JDK 17 для EDT 2026.1 или JDK 25 для EDT 2026.2.2 в параметрах своего запуска EDT.
Плагин не исправляет `1cedt.ini` или глобальные переменные среды. Проверенные JVM — Axiom 17.0.18 и 25.0.2.

## Выбор палитры

В 0.1.16 роли палитры также применяются к языку запросов QL/DCS, включая текстовые
контролы конструктора запроса. Флаг «Применять палитру BSL» управляет только BSL;
язык запросов следует общей палитре. Исходные цвета QL/DCS восстанавливаются
вместе с остальными цветами. Новые палитры и роли в этом выпуске не добавлены.

Откройте **Окно → Настройки** и найдите страницу **Темы EDT** в разделе **Внешний вид**.
В других локализациях путь может называться General → Appearance; можно использовать
фильтр «Темы EDT» в дереве настроек.

Выберите Darcula, Monokai, One Dark Pro, Dracula, GitHub Dark Default, Winter is Coming (Dark Blue), Night Owl, Ayu Dark (Bordered), Shades of Purple, Noctis Minimus или Visual Studio Dark (C/C++), настройте **Применять палитру BSL**,
нажмите **Применить** или **ОК**.
При первом применении плагин сохраняет исходные цвета и IDs тем, затем включает штатную Dark.
При смене профиля первичный снимок сохраняется. Выбор действует в этой рабочей области.

В 0.1.3 список палитр рисует фон и текст выбранной строки вместе, как список шрифтов.
Выбор мышью или Enter обновляет образец; Escape закрывает список без смены выбора.
Настройки EDT записываются после «Применить»/«ОК».

BSL включает девять проверенных категорий: встроенные функции, ключевые слова,
комментарии, операторы, основной текст, препроцессор, скобки, строки и числа.
Настройки цвета на уровне проекта могут иметь приоритет над workspace preferences.
Отдельная палитра языка запросов, прагм и меток не реализована; запрос внутри строки
использует доступное штатное поведение редактора.
Некоторые категории препроцессора и нативные полосы прокрутки сохраняют штатные цвета.

При выключенном BSL палитра BSL не применяется, а исходные BSL overrides сохраняются/возвращаются.
Цветовая палитра не меняет шрифт. Форматирование, сочетания клавиш и кодировка не меняются.
Для полного обновления уже открытых редакторов и нативных контролов может понадобиться перезапуск.

**Отмена** до нажатия «Применить» не меняет цвета. После «Применить» отмена диалога
сохраняет уже применённый профиль. Если переключить штатную тему Eclipse на Light или другую,
плагин освобождает профиль и сохраняет выбранную тему.

## Свои цвета палитр

В 0.1.4 на странице **Темы EDT** появился раздел **Палитра — 17 ролей**.
Выберите роль в таблице: видны её название, образец, HEX и пометка **Стиль**
или **Личный**. Под таблицей — объяснение применения; наведите на объяснение,
чтобы увидеть точные связанные настройки EDT. Общая роль может менять сразу
несколько областей: например, акцент используется для ссылок, границ при наведении
и встроенных функций BSL. Ошибки/предупреждения относятся к заголовкам формы,
а не ко всем маркерам и потокам консоли.

Нажмите кнопку с образцом для штатного выбора цвета или введите **#RRGGBB**
в поле HEX. Неверное значение блокирует **Применить/ОК**, даже если переключиться
на другую палитру. Исправьте значение либо сбросьте эту роль. Палитра редактируется
при выборе любой из одиннадцати палитр; при штатном оформлении редактор недоступен.

До применения меняются только локальные образцы интерфейса, BSL и списки на этой
странице. Образец интерфейса условный: он показывает роли панели, границ, выделения,
наведения, текста и заголовков, а не точный вид всех экранов EDT.
Цвета в таблице — значения профиля; ручные настройки EDT и настройки проекта могут
иметь другие эффективные значения.

Личные цвета хранятся **отдельно для каждой палитры в текущей workspace**.
Переключение профиля внутри диалога сохраняет все черновики. **Применить/ОК**
сохраняет правки палитр и применяет выбранную. **Отмена** отбрасывает только
ещё не применённое; уже подтверждённый Apply сохраняется.

**Вернуть цвет стиля** сбрасывает выбранную роль, **Сбросить палитру** — все 17
ролей текущего стиля. Сброс выполняется после Apply/OK и не сбрасывает остальные стили.
Явная правка или сброс заменяет соответствующие ручные цвета EDT. Остальные ручные
правки остаются защищёнными. Выбор встроенного цвета также считается явным действием.

При выключенном **Применять палитру BSL** личные цвета сохраняются, но соответствующие
категории BSL возвращаются к исходным значениям. Шрифт независим от палитры.
**Восстановить исходное оформление…** возвращает исходную EDT и сохраняет личные
варианты стилей для повторного выбора. Это отдельное действие от сброса к цветам стиля.

На небольшой странице используйте прокрутку: редактор палитры и шрифт находятся
в одной странице. Создание собственных стилей, экспорт/импорт и hover строк списков
в эту версию не входят.

## Шрифт кода

На той же странице **Темы EDT** в группе **Шрифт кода** выберите установленный шрифт
и размер в пунктах (1–200). Образец обновляется сразу; открытые редакторы изменятся после
**Применить** или **ОК**. До этого **Отмена** сохраняет прежний шрифт.
После применения **Отмена** закрывает диалог, сохраняя подтверждённый выбор.

Шрифт действует в текущей рабочей области и сохраняется после перезапуска. Используется
штатный общий текстовый шрифт EDT: выбор может затронуть и другие текстовые редакторы,
которые используют ту же настройку. Индивидуальные шрифты категорий подсветки или отдельных
редакторов не переопределяются. Плагин не устанавливает дополнительные шрифты Windows.

Шрифт не привязан к палитре: можно изменить его при **Штатном оформлении**.
Переключение палитры и кнопка **Восстановить исходное оформление…** не сбрасывают шрифт.

В 0.1.2 образец показывает цвета выбранной Darcula/Monokai ещё до применения темы:
комментарии, директивы, русские/английские ключевые слова, строку и числовой литерал.
При выключенной палитре BSL или выбранном «Штатном оформлении» образец отображается
без раскраски токенов. Это фиксированный пример, а не редактор произвольного BSL-кода.

В раскрытом списке шрифтов выбранная строка рисуется с контрастными цветами палитры.
Можно выбрать шрифт мышью или клавишами: Enter подтверждает строку, Escape закрывает
список без изменения имени. Нажатие Apply/OK подтверждает выбор для редакторов.

Чтобы вернуть шрифт, действовавший перед первым выбором через плагин, нажмите
**Вернуть исходный шрифт**, затем **Применить** или **ОК**. Это явное восстановление
заменяет и последующие ручные изменения шрифта в штатных настройках EDT.
**Отмена** до применения отменяет выбранное восстановление.
Сохраняется исходное значение настройки, включая отсутствие явного переопределения.

## Восстановление

На странице **Темы EDT** нажмите **Восстановить исходное оформление…**.
Обычное восстановление возвращает исходные значения и отсутствие явно заданных значений;
ручные изменения цветов, сделанные после включения профиля, сохраняются.
При наличии конфликтов доступно отдельное подтверждение принудительного возврата
первоначальных значений вместо таких правок.

Можно выбрать **Штатное оформление** и нажать «Применить»/«ОК» для безопасного выхода.
Чтобы принудительно убрать сохранённые конфликты, используйте кнопку восстановления.
После восстановления перезапустите EDT, если открытые редакторы ещё показывают прежние цвета.

Профиль не восстанавливается автоматически при обычном завершении EDT: поэтому выбор
сохраняется после перезапуска. Если применение прервалось, при следующем запуске
плагин сначала обрабатывает журнал восстановления. При повреждённом/неизвестном формате
он сообщает ошибку и сохраняет журнал; не удаляйте preference-файл до разбора проблемы.

## Удаление

1. Сначала восстановите исходное оформление, при необходимости разрешите конфликты.
   Если меняли шрифт, отдельно нажмите **Вернуть исходный шрифт → Применить**, когда хотите вернуть его.
2. Откройте **Справка → О программе → Подробности установки → Установленное ПО**.
3. Удалите **Темы EDT — цветовые палитры**, перезапустите EDT.

Удаление feature само по себе не возвращает preferences: код плагина уже не сможет
выполнить восстановление. Если удалили его с активным профилем, установите тот же ZIP,
восстановите цвета, затем удалите повторно.

Содержимое предпросмотра формы, MXL, графической схемы и макета оформления СКД
должно сохранять прикладной вид; plugin меняет оформление оболочки. Эти экраны требуют
ручной проверки на небольшом тестовом проекте перед использованием с рабочими проектами.
