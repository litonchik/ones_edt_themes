# Фон линейки редактора

Локальная доработка 0.1.23, 04.11.2026.

Фон левой линейки (номера строк, значки и сворачивание) использует уже существующую
настройку `AbstractTextEditor.Color.Background` и её флаг SystemDefault из общего
хранилища текстовых редакторов. Цвет цифр остаётся `lineNumberColor` (роль `disabled`).
Новых ролей, preference keys или настроек страницы тем не добавлено.

`EditorRulerColors.refresh` вызывается после штатного CSS и восстановления точных
preferences. Через публичное `IPreferenceStore.firePropertyChangeEvent` обновляется
модель штатной линейки: её делегат хранит собственный цвет для рисования цифр,
поэтому одного `Control.setBackground` недостаточно. Используется
`EditorsUI.getPreferenceStore`; Xtext language store не уведомляет эту линейку.
Значения настроек этим событием не записываются.

Сами контролы получаются через публичные `IEditorPart.getAdapter(IVerticalRulerInfo)`
и `CompositeRuler.getDecoratorIterator`. Их фон выравнивается с общей настройкой
редактора при активной палитре с явным фоном. Поддержаны повторное применение,
личный фон и новые/восстановленные редакторы, в том числе в новом рабочем окне.
Подписки на события частей/окон снимаются при остановке плагина.

При возврате оформления учитываются исходные preferences и штатные цвета CSS.
Колонка сворачивания определяется по публичной `ProjectionAnnotationModel`;
её исходный фон восстанавливается по текстовому viewer, как при штатном создании.
При выключенной палитре автоматические callbacks не переустанавливают её цвета.

Общий слой светлых панелей по-прежнему исключает содержимое редакторов.
Дополнительное обновление затрагивает только их левую линейку. Рисование цифр,
значков, отметок и обработчики сворачивания остаются штатными. Собственная
отрисовка полос прокрутки не добавлялась.

Первичные локальные источники от 04.11.2026: исходники Eclipse
`LineNumberColumn`, `LineNumberRulerColumn`, `AnnotationRulerColumn`,
`ProjectionRulerColumn`, `AbstractTextEditor` и `CompositeRuler` из целевой EDT.
Закрытые реализации прочитаны для диагностики, напрямую не используются;
reflection и патчи vendor bundles не применяются.
