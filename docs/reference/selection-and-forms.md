# Выделение строк и поля Eclipse Forms

Дата: 05.11.2026. Локальный кандидат 0.1.28.

0.1.27 исправляла отдельные фоны Git-декораций. Это не определяло цвет
нативного выделения SWT Tree/Table, особенно после потери фокуса.
В тестовой EDT 2026.1.3 GitHub Light Default давала RGB 70,70,70
для неактивного выделения вместо роли selection.background #CEE1F8.

Кроме того, Section/ExpandableComposite наследуют Canvas. Защита содержимого
редакторов останавливала обход на этих узлах Eclipse Forms, пропуская обычные
поля автора/коммиттера в настоящем EGit Staging. Одного CSS было недостаточно:
Text.getBackground() возвращал белый, а фактические пиксели оставались тёмными.

## Реализация

LightUiStyles обслуживает выделение Tree/Table во всех 19 активных профилях.
Публичный SWT.EraseItem заполняет выбранную строку текущими цветами выделения
из EditorsUI; это уже управляемые роли selection.background/selection.foreground.
Для выбранной строки снимаются только стандартные SELECTED/HOT/BACKGROUND:
иконки, текст, чекбоксы и рамку фокуса продолжает рисовать SWT/JFace.
SWT.HIDE_SELECTION сохраняет своё поведение. Обрабатываются одиночное,
множественное и неактивное выделение; после deselect работает обычная отрисовка.

Обход разрешён через публичный ExpandableComposite, но прочие Canvas и целые
поддеревья IEditorPart по-прежнему исключены. Обычные дочерние элементы Forms
получают фон/текст/disabled текущего профиля и в Light, и в Dark.
Для Text внутри Forms используется публичный setBackgroundImage с одноцветным
изображением 1×1: этот путь SWT устраняет тёмную нативную заливку Windows.
Штатное редактирование текста остаётся нативным. Чужие background images
сохраняются; собственное изображение заменяется при смене RGB и освобождается
при restore, остановке плагина или уничтожении контрола. Новых настроек,
ролей и обязательной зависимости от EGit нет.

В production не используются reflection, Win32 calls или замена vendor bundles.
Основание — исходники установленного SWT 3.124 (Tree/Table/Text), публичные
API Eclipse Forms и локальное воспроизведение в изолированных EDT.
EGit подключён только к тестовому fragment. Для выбора репозитория в настоящем
Staging тест использует IShowInTarget с test-only RepositoryNode; это не часть
поставки и не реализация плагина.
