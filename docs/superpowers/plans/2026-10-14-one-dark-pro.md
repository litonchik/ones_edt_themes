# One Dark Pro — реализация одной новой схемы, 0.1.6

Исполнение: самостоятельно в текущем проекте, без субагентов/worktree.
Пользователь 14.10.2026 согласовал предложенную очередь и попросил одну схему
за подход. Основа: [каталог](../../research/2026-10-14-theme-catalog.md), раздел 5.2.

Цель: третья палитра One Dark Pro, ID `one-dark-pro`, прежние 17 ролей,
личные варианты/Apply/OK/Cancel/reset/restore и независимый шрифт.
Реестр профилей в PaletteCatalog становится единственным источником IDs/имён
для загрузчика, drafts и UI. Snapshot/EDT settings contracts не меняются.
Низкий контраст исходного comment сохраняется как свойство исходной палитры;
пользователь может изменить его в существующем редакторе ролей.

Ограничения: EDT 2026.1.3+25, Eclipse 4.30.0, Xtext UI 2.33.0, Java 17,
BSL UI 23.0.1.v202609041212 и theming UI 2.1.0.v202609041212.
Только штатный Dark ID; рабочую EDT не менять; новые vendor bundles, API keys,
ПО и остальные темы не добавлять. Git разрешён после подтверждённого MVP.

## Существенные сценарии

Профиль с новым ID не должен потеряться из-за прежнего ternary UI. Существующие
personal keys остаются вне original snapshot; новая схема не затирает overrides
двух старых. Неизвестный persisted ID не должен ломать страницу или превращаться
в Darcula; записанные цвета/журнал сохраняются до явного выбора/restore.
Применение новой палитры с BSL=false сохраняет текущую защиту BSL.
Обычный selected foreground #D7DAE0 контрастен на фоне #404859; styled selection
glyph требует отдельной проверки. Hover строк списков остаётся отложенным.
