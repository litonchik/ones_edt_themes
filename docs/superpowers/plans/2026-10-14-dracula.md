# Dracula — одна новая схема, 0.1.7

Пользователь подтвердил работу 0.1.6 («работает») и согласовал следующую схему
по очереди. Исполнение самостоятельно в текущем checkout, без субагентов.
Основа: [каталог](../../research/2026-10-14-theme-catalog.md), раздел 5.4.

Цель: добавить базовую Dracula, ID `dracula`, в общий реестр и прежние 17 ролей.
Это самостоятельная схема, отличная от существующей Darcula. Soft и другие темы
в этот подход не входят. Сохраняются исходные comment/disabled #6272A4,
line #353747, hover #3B3E4F и остальные значения из анализа.
Низкий исходный контраст вторичного текста явно фиксируется в документации.

Target: EDT 2026.1.3+25, Eclipse 4.30.0, Xtext UI 2.33.0, Java 17,
BSL UI 23.0.1.v202609041212, theming UI 2.1.0.v202609041212.
Штатный Dark ID, прежние settings, snapshots, personal keys, шрифт и UI API.
Рабочую EDT не менять; использовать .work/edt-test/workspace-probe.
