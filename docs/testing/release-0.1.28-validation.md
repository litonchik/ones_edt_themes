# Публикация 0.1.28 и GitHub Pages

Дата подготовки: 05.11.2026. Пользователь подтвердил исправление 0.1.28 и
разрешил push, релиз и публикацию сайта обновлений.

Используется проверенный bundle `0.1.28.202611051018`, без повторной сборки.
SHA-256 ZIP: `fd30cdb923de6d8cf652c4f45c736ed9412e8e6013943a94667447c5810648b8`.
116 unit tests и 8140 runtime PASS на трёх Windows EDT —
[итоговая матрица](selection-validation.md).
Шесть тестов упаковки p2-сайта пройдены перед публикацией.

Публикуется накопленный исходный код восьми светлых схем и общих исправлений
0.1.17–0.1.28. Автор коммита использует локальную GitHub noreply-почту.
Локальные кэши, тестовые EDT, workspace и dist/ в Git не входят.

Существующий workflow `Publish update site` берёт ZIP и SHA-256 из последнего
стабильного релиза, проверяет целостность и публикует его p2-файлы через
GitHub Pages. CI не пересобирает EDT-плагин.

Результаты публикации, HTTP-проверок и установки по URL будут добавлены
после выполнения этих этапов; этот документ пока фиксирует подготовку.

Для публикации из новых файлов исключены все новые диагностические .log. Они сохранены локально.
Из новых сводных отчётов удалены абсолютные пути локального окружения;
неизменённые оригиналы сохранены в локальном .work/private-release-evidence/.
Результаты assertions, сводки, SHA-256 и снимки остаются в Git.
