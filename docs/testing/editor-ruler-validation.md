# Фон нумерации — локальный кандидат 0.1.23

Дата: **04.11.2026**. По запросу пользователя исправлен фон номеров строк
и соседних колонок значков/сворачивания в левой линейке редактора.
[Механизм и первичные локальные источники](../reference/editor-ruler.md).

## Исправление

Штатная линейка номеров хранит собственный цвет рисования и подписана на
`EditorsUI.getPreferenceStore`. Обновление Xtext language store не меняло её,
а после native CSS контролы оставались светло-серыми. Теперь после CSS
и восстановления preferences обновляются штатная модель и контролы линейки.
Фон берётся из общей настройки редактора, включая личные цвета палитры.
Значения настроек не переписываются событием обновления; новых ролей и keys нет.

При восстановлении учитывается особенность колонки сворачивания: её начальный
фон соответствует текстовому viewer. Для распознавания используется публичная
`ProjectionAnnotationModel`, без доступа к закрытой реализации колонки.
Подписки на события частей/окон поддерживают новые редакторы и снимаются
при остановке. Собственная отрисовка полос прокрутки не добавлялась.
