# Проверка выделения и Eclipse Forms — 0.1.28

Дата: 05.11.2026. Windows x64. Локальный кандидат; стабильная публичная версия 0.1.16.

## Воспроизведение и причина

Предыдущая 0.1.27 управляла цветами Git-декораций, но не нативным выделением
Tree/Table и не полями за Canvas-узлами Section/ExpandableComposite.
На EDT 2026.1.3 неактивное выделение Tree имело RGB 70,70,70 при палитре
GitHub Light Default с selection.background #CEE1F8. Настоящие поля автора
и коммиттера EGit были тёмными, хотя getBackground() возвращал белый.
[Отчёт до](2026-11-05-selection/2026.1.3-before.txt),
[полный снимок до](2026-11-05-selection/before.png).

В 0.1.28 общий механизм исправлен для всех 19 палитр.
[Устройство и публичные API](../reference/selection-and-forms.md).
