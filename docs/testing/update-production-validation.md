# Производственный индикатор без локального примера — 0.1.30

Дата: 09.11.2026. Пользователь подтвердил работу локального примера («работает»),
попросил убрать его из рабочего решения и разрешил push. Его ОС/сборка отдельно
не сообщены. Предыдущие [проверки индикатора](update-indicator-validation.md) и
[локального примера](update-preview-validation.md) сохранены как история.

Режим примера полностью удалён из production Java-кода: нет кнопки, transient-флага,
API для синтетической версии и специального режима сведений. Индикатор использует
реальное состояние проверки и её кэш. Подмена источника для автоматизированных
испытаний выполняется только из test-only fragment, отсутствующего в ZIP.
Apply/OK с неизменным флагом по-прежнему не отменяют активную проверку.

## Проверки

Maven/Tycho Verify и состав ZIP — PASS. **137 unit tests**, **6 тестов упаковки сайта**
и **90 адресных runtime PASS, 0 FAIL**.

Точные сборки: 2026.1.3+25, 2026.1.2+2, 2026.2.2+21. На каждой проверены:

- отсутствие примера на странице до и после появления настоящего результата;
- старая версия источника не создаёт cache или значок;
- ручная проверка доступна при отключённой автоматической;
- Apply без изменения флага сохраняет активный запрос и результат AVAILABLE;
- ответ источника даёт полный видимый значок и обычную подсказку с номером;
- фокус редактора и набор видимых окон сохраняются;
- Cancel не меняет сохранённый флаг;
- немодальные сведения открываются только по нажатию, действия реального релиза доступны;
- открытие сведений не вызывает установку, явное «Обновить» вызывает штатную команду;
- только это явное действие регистрирует/включает фиксированный p2-сайт;
- исходные registration/enable flags менеджеров p2 восстанавливаются после проверки;
- закрытие сведений сохраняет реальное обновление, отключение скрывает значок;
- остановка монитора и пустой журнал оформления после сценария.

Нативная команда перехвачена test-only handler: подтверждена маршрутизация
явного действия, новая версия через мастер реально не устанавливалась.
0.1.31 на снимках — ответ тестового источника, а не опубликованный релиз.
Mac, физическая смена DPI и внешние AI-агенты отдельно не проверялись.
