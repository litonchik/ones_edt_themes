# Темы EDT 0.1.16

Первый публичный релиз: 11 тёмных палитр интерфейса и редакторов 1С:EDT,
личные цвета и настройка шрифта кода с предпросмотром.

- Поддержаны точные сборки Windows x64 EDT 2026.1.2+2 и 2026.1.3+25 с Java 17,
  а также 2026.2.2+21 с Java 25.
- Исправлено обновление семантических цветов вызовов BSL при смене палитры
  и восстановлении оформления: редактировать текст для обновления цветов не нужно.
- Добавлены 21 цветовая настройка QL/DCS с восстановлением исходных значений.
- Установка из p2 ZIP или с сайта обновлений:
  `https://litonchik.github.io/ones_edt_themes/repository/`.

В EDT: **Справка → Установить новое ПО… → Добавить…**, затем укажите URL
либо выберите **Архив…** и `edt-themes-0.1.16.zip`. Выберите компонент
**Темы EDT — цветовые палитры**, завершите установку и перезапустите EDT.
Source code ZIP/tar.gz содержит исходники и для установки не подходит.

Проверки сборки: **79 unit tests и 1104 runtime assertions** на трёх EDT.
Полный мастер запроса с metadata-проектом и новые версии на macOS не проверены.
EDT 2025 и Linux не поддерживаются. Собственные bundle не подписаны сертификатом;
при установке EDT может запросить доверие. Базовые bundle EDT в поставку не входят.
