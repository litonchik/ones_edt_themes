# Среда разработки и сведения для продолжения

Дата: 13 октября 2026 года. Цель: EDT 2026.1.3 на Windows x64.

## Фактическое окружение реализации

Проверены Maven **3.9.11**, Tycho **4.0.13**, Axiom Java **17.0.18**,
локальный Directory target установленной EDT. `scripts/build.ps1 -Action Verify`
выполняет unit tests, Tycho reactor, проверку class-file major 61/состава p2 ZIP и SHA-256.
Maven вызывается по полному пути; переменные JAVA_HOME, MAVEN_BASEDIR, MAVEN_SKIP_RC
и MAVEN_OPTS сохраняются и восстанавливаются в finally. Временные файлы Java и `.cache/m2`
находятся внутри проекта.

Первоначальный Maven 3.10.0 получил зависимости, но не смог создать компонент Tycho
`MavenTargetLocationFactory`. Пользователь установил Maven 3.9.11 в `C:\apps\apache-maven-3.9.11`;
с ним reactor собирается. [Первичный отчёт Apache с таким же классом ошибки](https://github.com/apache/maven/issues/11493),
[требования Tycho по версиям](https://tycho.eclipseprojects.io/doc/5.0.3/target-platform-configuration/plugin-info.html).
Источники проверены 13 октября 2026. Tycho 5 требует JDK 21, поэтому для целевого JDK 17
сохранён Tycho 4.0.13.

Тестовая копия: `.work/edt-test`. Для служебного p2 директор использует отдельную
минимальную configuration без запуска EDT bundles. Для workbench probe перенаправлены
process-local APPDATA/LOCALAPPDATA/USERPROFILE/TEMP/TMP и Java user.home внутри `.work`.
Одного `-data` недостаточно: `LibraryRepository.getRealLibraryRepositoryPath()` в EDT
берёт общий каталог из APPDATA. Это подтверждено байткодом установленного bundle.
Рабочая EDT и глобальные переменные не менялись.

Подробности тестов, скрипты воспроизведения и ограничения — `docs/testing/mvp-validation.md`.

## Почему нельзя просто повторить руководство

Раздел [настройки среды](https://edt.1c.ru/dev/ru/docs/plugins/project/env-setup/) рекомендует JDK 17, Eclipse 2022-03 и Maven 3.6.3+. Это описание демонстрационного окружения, а не доказательство соответствия EDT 2026.1.3.

Проверенный [BOM текущего примера](https://github.com/1C-Company/dt-example-plugins/blob/master/bom/pom.xml) уже задаёт Java 25, Maven 3.9.9 и Tycho 5.0.2. Его [target](https://github.com/1C-Company/dt-example-plugins/blob/master/targets/default/default.target) использует EDT 2026.2 и Eclipse 2025-12. Эти версии не принимаются за основу нашей платформы.

В [истории сборок примера 1С](https://github.com/1C-Company/dt-example-plugins/actions) видна отдельная миграция на 2026.1 — commit `921c30c` / PR #61. Это кандидат для изучения исторического окружения. Содержимое файлов этой ревизии получить в ходе исследования не удалось; версии её зависимостей не подтверждены.

Согласно [системным требованиям вендора](https://edt.1c.ru/docs/intro/requirements.php), начиная с EDT 2025.1 Java поставляется вместе со средой. Наличие этой Java не доказывает наличие всех инструментов JDK для сборки.

## Будущая изоляция проверки

Maven запускать по полному пути. Для дочернего процесса выбирать `JAVA_HOME=C:\Program Files\Axiom\AxiomJDK-Pro-17-Full`; не выполнять глобальные `setx`/изменения PATH. `MAVEN_BASEDIR` явно задавать каталогом проекта: без этого batch launcher пытается искать `.mvn` в родительских каталогах и в текущей песочнице выдавал `Access is denied`. После явного задания basedir сообщение отсутствовало, `--version` завершился с кодом 0.

После поручения реализации использовать отдельную рабочую область EDT и тестовый проект. Установку p2 сначала проверять в отдельной копии/экземпляре целевой EDT. Не использовать рабочую конфигурацию пользователя для экспериментов с preference keys.

На первом этапе сборка может обращаться к Maven Central и p2-репозиториям. Установка готового ZIP должна использовать уже имеющиеся зависимости EDT. Не помещать сторонние базовые библиотеки в архив темы ради автоматического обновления платформы.
