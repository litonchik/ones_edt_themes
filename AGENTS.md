# Правила проекта

## Цель и текущий этап

Разработать плагин цветовых тем интерфейса и редакторов для 1С:EDT 2026.1.3. Начальные предлагаемые темы — Darcula и Monokai.

Пользователь согласовал подход MVP и утвердил план `docs/superpowers/plans/2026-10-13-edt-themes-mvp.md`. Реализация продолжена по handoff самостоятельно, без субагентов и Git. Созданы код, tests, feature/repository, инструкция и p2 ZIP. Фактические проверки и оставшаяся ручная матрица — `docs/testing/mvp-validation.md`; журнал — `docs/testing/progress.md`. Повторное согласование подхода и плана не требуется.

## Технические ориентиры

- Проверять зависимости именно для 2026.1.3. Текущий `master` примера 1С уже ориентирован на 2026.2; не копировать его версии без проверки.
- Локально подтверждены Eclipse 4.30.0 и Java 17. Использовать установленный `C:\Program Files\Axiom\AxiomJDK-Pro-17-Full` для будущей разработки/проверки; PATH сейчас указывает на JDK 25 и не определяет целевую Java.
- Maven 3.10.0 запускается с Java 17, но Tycho 4.0.13 падает с `No implementation for MavenTargetLocationFactory was bound`. Пользователь установил и сообщил `C:\apps\apache-maven-3.9.11\bin`; рабочий build default теперь `C:\apps\apache-maven-3.9.11\bin\mvn.cmd`. Вызывать его по полному пути с process-local `JAVA_HOME` на JDK 17, `MAVEN_BASEDIR` на проект и `MAVEN_SKIP_RC=true`; не менять глобальную среду. Java temporary directory задаётся внутри `.work`, чтобы избежать ошибок sandbox при сохранении p2 cache.
- EDT распознаёт Dark по точному ID `org.eclipse.e4.ui.css.theme.e4_dark`. Для MVP рекомендованы профили палитр поверх штатной Dark; см. `docs/research/2026-10-13-installed-platform.md`.
- Разделять CSS интерфейса, реестр цветов EDT и настройки редакторов. Не считать одну CSS-тему достаточной для подсветки BSL.
- Предпочитать публичные extension points и API Eclipse/EDT. Не патчить JAR вендора и не использовать reflection для обхода внутренних контрактов.
- Не придумывать идентификаторы цветов и preference keys. Получать их из установленной целевой платформы и проверять применением в отдельной тестовой рабочей области.
- Сохранять исходные значения затрагиваемых настроек, включая отсутствие явного значения; обеспечивать восстановление.
- Сохранять пользовательский вид предпросмотра формы и содержимого макетов, перечисленных в документации вендора как исключения из темизации.
- Поставлять собственные bundles через feature и локальный p2 ZIP. Не включать замену базовых bundles Eclipse/EDT в установку темы.
