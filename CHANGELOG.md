# История изменений

## 0.1.29 — 06.11.2026

- Добавлен выключенный по умолчанию флаг значков метаданных Visual Studio Light / Dark
  с предпросмотром и Apply/OK/Cancel; 49 рисунков в Light/Dark наборах.
- Известные исходные картинки заменяются через публичный декоратор Eclipse;
  неизвестные и составные сохраняются штатными. Палитры и шрифт независимы.
- Подготовлены PNG для 100–400%, сохранены SVG, MIT и точная upstream-ревизия.
- [Устройство](docs/reference/chroma-icons.md) и [проверки](docs/testing/chroma-icons-validation.md).
- Установка через GitHub Pages и ZIP из [Releases](https://github.com/litonchik/ones_edt_themes/releases/tag/v0.1.29).

## 0.1.28 — 05.11.2026

Публичный релиз объединяет изменения локальных кандидатов 0.1.17–0.1.28.

- Добавлены восемь светлых тем: GitHub Light Default, Winter is Coming (Light),
  Night Owl Light, Ayu Light (Bordered), Noctis Lux, Visual Studio Light (C/C++),
  Noctis Hibernus и Noctis Lilac. Всего 19 схем — 8 светлых и 11 тёмных.
- Добавлен переключатель «Тёмные / Светлые», оформление обычных панелей
  и фон нумерации кода; сохранены отдельные личные варианты каждой темы.
- Исправлены обновление подсветки QL/DCS и embedded-редакторов,
  Git-подписи ресурсов, выделение строк и поля Eclipse Forms.
- При переходе светлая ↔ тёмная после применения требуется перезапуск EDT.
- Проверены Windows EDT 2026.1.2+2 / 2026.1.3+25 (Java 17) и 2026.2.2+21
  (Java 25): 116 unit tests и 8140 runtime PASS в итоговой матрице.

Последнее исправление:

- Исправлен фон активного, неактивного и множественного выделения Tree/Table
  для всех 19 тем, включая снятие выделения.
- Исправлены поля Eclipse Forms, в том числе реальные «Автор» и «Коммиттер»
  в EGit Staging. Проверяется фактическая заливка, включая disabled-состояние.
- Сохранены 17 ролей, палитры и содержимое редакторов; ресурсы отрисовки
  удаляются при восстановлении исходных настроек.
- [Причина и проверка](docs/testing/selection-validation.md).
- Установка через GitHub Pages или ZIP из [Releases](https://github.com/litonchik/ones_edt_themes/releases/tag/v0.1.28).

  BSL-сравнения после смены палитры требуется переоткрыть окно.
